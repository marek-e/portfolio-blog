Blink is a small native macOS app that sits between your apps and your browsers. When you open a link from Mail, Slack, Notes or anywhere else, Blink either asks which browser to use or sends the link straight to the browser your rules pick.

## What it does

- A compact picker opens next to the pointer with your browsers and the link's host. Press 1 to 9, use the arrow keys, or click.
- Rules route links by domain and path, for example `example.com/team` to a work browser. The first matching rule wins.
- It knows browser profiles: Arc spaces, Dia, Chrome, Brave, Edge, Vivaldi, Zen and Firefox. A rule can send a domain to one profile.
- When a browser is missing or refuses a link, Blink keeps the link and lets you retry, pick another browser or copy it. It never falls back silently.
- Everything stays on your Mac. Settings live in one JSON file, there's no history, no network request, and URLs are never logged.

## Install

Download the DMG from the [GitHub releases](https://github.com/marek-e/blink/releases), or install it with Homebrew:

```sh
brew tap marek-e/blink https://github.com/marek-e/blink
brew install --cask marek-e/blink/blink
```

Releases aren't signed with an Apple Developer ID yet, so macOS blocks Blink the first time you open it. Open it once, then go to System Settings › Privacy & Security and click **Open Anyway**. You only need to do this once.

Requires macOS 14 Sonoma or later.
